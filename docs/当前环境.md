## 显存硬约束

6 GB VRAM 是本项目最重要的工程边界。默认按以下假设设计：

- Batch Size = 1
- 起步分辨率 512–768，不要一上来 1024+ 并叠加多种控制器
- 同时加载的大模型越少越好：Checkpoint + IPAdapter + 多个 ControlNet + Upscale 很容易爆显存
- 禁止无必要地重复加载同一模型
- High-Res / Upscale / 二次采样尽量拆成独立实验，不要默认塞进主图
- 优先考虑：较小 checkpoint、卸载不用的节点、降低中间图像尺寸、关闭预览大图

无法确认能否在 6 GB 下运行的方案，必须在实验文档里标明「可能无法在本机运行」，并给出降配路径。

## 环境注意

- 探测到的系统 Python 是 3.13.1。ComfyUI 生态通常更稳的是 3.10–3.12。若实际运行环境不同，以 ComfyUI 所用 venv 为准，并回写本页。
- 未确认 PyTorch / CUDA 版本前，不要假设 fp8、部分量化或特定自定义节点可用。
- 模型文件不要提交进本仓库。只在 `docs/模型说明.md` 记录名称、用途与本机路径。
