# 方案一开发文档：原人物锁定换装

## 1. 文档目的

在现有 ComfyUI 工作流基础上开发“只更换服饰”的人物编辑工作流。

核心目标：

> 最大程度保留原始人物像素，仅重新生成服饰区域。

该方案不负责改变人物姿势。

推荐工作流名称：

`01_WAI_人物锁定换装.json`

---

# 2. 当前基线

基于现有工作流继续开发。

当前基础模型：


---

# 3. 开发目标

必须尽量保持：

- 头部不变
- 五官不变
- 发型不变
- 发色不变
- 肤色不变
- 身材比例不变
- 四肢轮廓不变
- 原始姿势不变
- 原始背景默认不变

允许变化：

- 上衣
- 裙装
- 裤装
- 泳装
- 外套
- 鞋袜
- 配饰
- 与服装直接相关的遮挡关系

---

# 4. 核心设计原则

本方案禁止整个人物重新生成。

采用：

```text
原图
+
服装区域 MASK
+
Inpaint
```

而不是：

```text
原图
→ 普通 Img2Img
→ 整张重新采样
```

基本原则：

> MASK 外的区域尽量保持原始像素。

# 7. MASK 规则

MASK 是本方案最重要的部分。

## 应该 Mask

只 Mask：

```text
需要替换的服装
鞋子
袜子
服饰附件
服装覆盖区域
```

## 原则上不要 Mask

```text
脸
眼睛
鼻子
嘴
耳朵
头发
裸露肩部
裸露手臂
手
腰部裸露皮肤
大腿裸露皮肤
小腿
脚
背景
```

---

# 8. Mask 边缘

服饰和皮肤交界不能使用完全硬边。

推荐：

```text
Mask Grow:
4–12 px

Mask Blur:
4–10 px
```

根据图像尺寸测试。

原则：

> 只扩展到足以重新生成服装边缘的位置，不大面积侵入皮肤。

# 10. 第二遍精修

第二遍不是必须。

只有出现：

- 衣服边缘破碎
- 花纹模糊
- 衣服与皮肤连接异常
- 饰品结构异常

时才启用。

建议：

```text
Steps: 10–14
CFG: 4–5
Denoise: 0.12–0.18
```

推荐默认：

```text
Steps: 12
CFG: 4.5
Denoise: 0.15
```

第二遍仍然只处理服饰区域。

禁止第二遍重新采样整张人物。

---

# 11. Prompt 架构

Prompt 拆成：

```text
[质量]
+
[固定人物特征]
+
[新服装]
+
[原场景]
```

固定人物部分保持不变。

例如：

```text
1girl,
adult woman,
same person,
same face,
long black hair,
blue eyes,
pale skin,
tall slender body,
long legs,
slim waist
```

用户每次主要修改：

```text
[CLOTHING]
```

---

# 12. 负向提示词

重点限制：

```text
different person,
different face,
different hairstyle,
different hair color,
different body type,
different skin tone,
short legs,
wide waist,
different proportions
```

但必须明确：

> Negative Prompt 只能辅助，人物锁定主要依靠“非 Mask 区域不重新生成”。

# 14. 验收标准

同一张原图连续测试至少 5 套服装。

检查：

- [ ] 五官肉眼无明显变化
- [ ] 发型主体无明显变化
- [ ] 发色一致
- [ ] 肤色一致
- [ ] 肩宽一致
- [ ] 腰宽一致
- [ ] 腿长比例一致
- [ ] 原姿势一致
- [ ] 背景基本一致
- [ ] 服装完成目标变化
- [ ] Mask 边缘不存在明显接缝
