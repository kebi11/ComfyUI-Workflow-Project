## 相对 v1 改了什么

一张手绘 Mask 拆成三套：

| Mask | 节点 | 职责 | 默认参数 |
|---|---|---|---|
| Generation | 13→16 | 模型在哪里造新衣服 | Grow 12 / Blur 8 |
| Composite | 30→33 | 新衣服怎么柔和贴回原图 | Grow 6 / Blur 12 |
| Seam | 35→40 | 第二遍只修接缝环带 | Outer +10 / Inner -4 / Blur 6 |

另外：

- Node 18 `grow_mask_by` 改为 `0`，避免和 Generation Grow 叠加
- Node 34：第一遍 Decode 后 `ImageCompositeMasked`，Mask 外恢复 Node 5 原像素
- Node 22 / 29 改为看 Composite 后的图
- Node 23 建立在 Composite 结果上，不再吃未贴回的 Decode
- Node 24 默认接 Seam Mask，不是整件 Generation Mask
- Node 41：最终再 Composite 一次，锁住头/肤色/背景
- 服装 Prompt 补了接触阴影 / 光影连续语句

本机 `GrowMask` 支持 `expand = -4`，因此自动做了 Ring Mask，不用手动画接缝。

## 怎么用

1. 加载本文件，不要覆盖 v1
2. 涂整件衣服，黑底亮白，不要开负面
3. 只改「正向-新服装」
4. 第一遍 denoise `1.00`，第二遍 `0.15`
5. 看「预览第一遍（已Composite）」：Mask 外必须是原图
6. 衣服内部花纹不好时，把 Node 24 的 Mask 临时改接到 Node 16，修完改回 Node 40

## 分层怎么调

| 现象 | 先动什么 |
|---|---|
| 一条明显边界线 | Composite Blur ↑，Seam Blur ↑ |
| 衣服像贴上去 | Generation Grow ↑ |
| 新衣服侵蚀皮肤 | Generation Grow ↓，Composite Grow ↓ |
| 第二遍越修越假 | Seam 缩小，Denoise 0.15→0.12 |
| 衣服本身不够精致 | Node 24 临时改接 Generation |

不要默认上「分层严重」那一档。
