# 高级自动换装工作流 v1 开发文档

## 1. 文档定位

本文档用于正式定义新的主线工作流：

`WAI_AutoClothes_Inpaint_v1`

该工作流用于在 ComfyUI 中实现：

- 自动识别服装区域
- 自动保护头部/头发/皮肤/无关身体区域
- 自动生成高质量服装编辑 Mask
- 基于 WAI-Illustrious + Inpaint 架构稳定换装
- 尽量避免手工 Mask 带来的不稳定
- 为后续“姿势+换装”与“大幅姿势改变”预留扩展接口

## 2. 为什么要重构，而不是继续增强旧工作流

旧工作流主逻辑：

手工 Mask → Inpaint → Composite → Seam 修补 → 定点修补

主要问题：

1. Mask 入口本身不稳定，过度依赖手工绘制。
2. 边界质量难统一，透明纱、发丝遮挡、裙摆、腰线都很难画稳。
3. 后续只能不断补丁式修复，越来越复杂。
4. 不适合作为长期主生产流。

因此新工作流应重构成：

自动分割 + 自动保护 + 自动边缘精修 + 局部 Inpaint

## 3. 工作流目标

### 主目标
- 自动识别需要更换的服装区域
- 尽量避免手工涂 Mask
- 人物身份尽量保持
- 脸、头发、肤色、身材、背景尽量不变
- 新衣服边界自然
- 适应透明/半透明旧衣物
- 适应 WAI / Illustrious / SDXL 模型体系
- 适配 RTX 4050 Laptop 6GB

### 非目标
第一阶段不追求：
- 姿势改变
- 大幅人体重建
- 多人物自动换装
- 一开始就加入 IPAdapter / FaceID / ControlNet / OpenPose

## 4. 总体架构

新工作流由 6 个模块组成：

1. 自动服装分割
2. 人物保护区生成
3. SAM2 精修轮廓
4. VITMatte 边缘精修
5. Crop & Stitch 局部裁切与融合
6. Fooocus Inpaint + WAI 生成

完整流程：

原图
→ 自动服装分割
→ 粗服装 Mask
→ 人物保护区生成
→ 编辑候选 Mask
→ SAM2 精修轮廓
→ 精修轮廓 Mask
→ VITMatte / Edge Ultra Detail
→ 高质量最终编辑 Mask
→ Inpaint Crop
→ 局部裁切图 + 裁切 Mask
→ Fooocus Inpaint + WAI
→ 局部换装图
→ Inpaint Stitch
→ 最终成品

## 6. 模块设计

### 模块 1：自动服装分割
目标：自动找出需要更换的服装区域。

推荐主模型：
SegformerB2ClothesUltra

输出：
粗服装 Mask

建议：
- 只换裙子：提取 skirt
- 只换上衣：提取 upper clothes / coat
- 换整套：提取 upper clothes / dress / skirt / pants / belt / shoe / socks / coat

原则：
不要直接将其作为最终编辑 Mask，它只是粗语义区域。

### 模块 2：人物保护区生成
目标：自动生成不允许被随意修改的人体区域。

推荐保护区域：
- face
- hair
- left_arm
- right_arm
- left_leg
- right_leg
- hands
- neck（按需）

输出：
Protected Mask

逻辑：
Edit Candidate Mask = Clothes Candidate Mask - Protected Mask

### 模块 3：SAM2 精修轮廓
目标：将粗服装 Mask 的边界修到更贴近真实轮廓。

推荐模型：
SAM2.1 Base+

为什么不是 Large：
- 对 4050 6GB 更友好
- 精度已经足够高
- 性能/显存更平衡

输入：
粗服装 Mask 或由其生成的 BBox + Mask guidance

原则：
不要让 SAM2 从零找衣服，只让它负责贴边。

输出：
Refined Contour Mask

### 模块 4：VITMatte / Edge Ultra Detail 边缘精修
目标：解决透明纱、半透明裙摆、发丝与衣服边界、柔边材质等问题。

推荐节点：
- MaskEdgeUltraDetailV2
- MaskEdgeUltraDetailV3

输出：
Final Edit Mask

这是后面 Crop & Inpaint 真正要用的 Mask。

### 模块 5：Crop & Stitch
目标：
只裁衣服及其必要上下文区域，用更合适的局部分辨率生成，再自动融合回原图。

推荐节点：
- Inpaint Crop
- Inpaint Stitch

推荐初始参数：
- mask_fill_holes = true
- mask_expand_pixels = 8~16
- mask_blend_pixels = 12~24
- context_from_mask_extend_factor = 1.5~2.0
- target size = 1024×1024
- device = CPU（第一阶段）

输出：
- cropped_image
- cropped_mask
- stitch object

### 模块 6：Fooocus Inpaint + WAI
目标：
在局部裁切图上，使用 WAI-Illustrious 进行稳定换装。

模型：
waiIllustriousSDXL_v170.safetensors

结合方式：
- Checkpoint Loader 加载 WAI
- Load Fooocus Inpaint
- Apply Fooocus Inpaint
- VAE Encode & Inpaint Conditioning
- KSampler
- VAEDecode

推荐模式：

#### Mode A：真正换装
适用于：
- 连衣裙 → 上衣 + 短裙
- 透明纱 → 不透明服装
- 大改轮廓

参数建议：
Denoise = 0.85~1.00

#### Mode B：轻度服装精修
适用于：
- 改颜色
- 改褶皱
- 改局部领口

参数建议：
Denoise = 0.50~0.75

## 7. 整体工作流输入输出定义

### 输入
必要输入：
- 原人物图
- 服装修改提示词
- 换装目标选项（如“上衣/裙子/整套服装”）
- 随机种子或固定种子
- 模式（完全换装 / 小改精修）

可选输入：
- 服装风格参考图（后续版本）
- 固定服饰库（后续版本）

### 输出
- 最终成品图
- 中间 Mask 预览
- 局部裁切图
- 可选中间结果：
  - 粗服装 Mask
  - 保护区 Mask
  - SAM2 精修 Mask
  - VITMatte 最终 Mask

## 8. 节点级开发顺序

### Phase 1：最小可用版本
先搭：
SegformerB2ClothesUltra
+ Protected Mask（简化）
+ Crop & Stitch
+ Fooocus Inpaint

目标：先验证“自动换装”能跑通。

### Phase 2：提高轮廓稳定性
增加：
SAM2.1 Base+

目标：修正衣服外轮廓、裙摆边缘、复杂遮挡边界。

### Phase 3：解决透明边缘
增加：
MaskEdgeUltraDetailV3 / VITMatte

目标：解决透明纱、薄纱、裙摆、柔边问题。

### Phase 4：加入二次语义保险
增加：
Human Parser ATR / LIP

目标：让服装识别与人物保护更加稳健。

## 9. 4050 6GB 适配原则

必须坚持：
Batch = 1

第一阶段关闭：
- IPAdapter
- FaceDetailer
- OpenPose
- 多 ControlNet
- 整图二次高清采样
- 大量并行分支

优先使用：
- 局部 1024×1024 crop
- Crop / Stitch CPU 模式
- 单次 Inpaint 优先

如果仍然爆显存，回退顺序：
1. Crop / Stitch 设备改 CPU
2. 目标 crop 改为 896×896
3. 降低上下文扩大倍数
4. 暂时关闭 VITMatte 精修模块
5. 暂时关闭 Human Parser 验证

## 10. Prompt 设计原则

### 正向 Prompt
重点写：
- 新服装类型
- 材质
- 轮廓
- 褶皱
- 光照与接触关系

示例：
masterpiece, best quality, amazing quality,
white sleeveless blouse,
high-waisted opaque black pleated skirt,
clean garment silhouette,
natural clothing folds,
natural clothing-body contact,
soft contact shadows,
consistent lighting

### 负向 Prompt
重点限制：
bad quality, worst quality, worst detail,
double clothing,
ghost fabric,
floating cloth,
blurry hemline

不建议再大量写：
same face / same hair / same body / same person

因为人物保持主要依赖：
自动保护 Mask + Crop & Stitch

## 11. 实验设计

### EXP-01：验证最小主线
固定：
- 原图
- 目标服装
- Seed
- Prompt
- 只开最小工作流

观察：
- 是否成功换装
- 头部是否稳定
- 裙摆是否有残影
- 是否仍需大量手工修补

### EXP-02：比较有无保护区
对照：
- 只用服装分割 Mask
- 服装分割 Mask - Protected Mask

观察：
- 脸和头发是否更稳定
- 裸露皮肤是否更稳定

### EXP-03：比较有无 SAM2
对照：
- Segformer 粗 Mask
- Segformer + SAM2 精修

观察：
- 裙摆边界
- 腰线边界
- 头发遮挡边界
- 鞋袜交界

### EXP-04：比较有无 VITMatte
对照：
- SAM2 后直接进入 Inpaint
- SAM2 + VITMatte 后进入 Inpaint

观察：
- 透明纱残留
- 软边质量
- Alpha 边缘自然度

### EXP-05：Fooocus Inpaint 参数
完全换装：
Denoise = 0.85 / 0.90 / 0.95 / 1.00

轻度精修：
Denoise = 0.50 / 0.60 / 0.65 / 0.75

## 12. 验收标准

- 自动找到服装区域
- 不依赖手工主 Mask
- 脸和头发主体基本不变
- 无关裸露皮肤基本不变
- 身材比例基本不变
- 新服装结构正常
- 旧服装无明显残影
- 透明纱不会在新衣边缘残留
- 腰线自然
- 裙摆边缘自然
- Stitch 后无明显接缝
- 单次主流程即可得到可用结果

## 16. 最终结论

本项目后续主线建议明确为：

重构新的自动化高级换装工作流，而不是继续围绕旧手工 Mask 工作流打补丁。

核心原因：
- 手工 Mask 本身不稳定
- 旧流程越来越复杂
- 需要更高自动化和更强可维护性
- 后续还要扩展姿势控制与身份保持

正式主线：
WAI_AutoClothes_Inpaint_v1

技术路线：
SegformerB2ClothesUltra
+ Human Parser
+ SAM2
+ VITMatte
+ Crop & Stitch
+ Fooocus Inpaint
+ WAI-Illustrious

这将作为后续全部开发与实验的基线。
