# 参数说明

只记录经过验证、或至少跑过对照实验的参数。重点写 **参数变化 → 实际视觉结果**，不要只留数字。

状态约定：

- `未测`：默认值 / 行业常见起点，本仓库尚未对照
- `观察中`：有实验，结论未稳
- `已验证`：至少一轮单变量实验支持

## 采样

| 参数 | 当前值 | 状态 | 观察 |
|---|---|---|---|
| Sampler | euler_ancestral | 观察中 | 沿用原 WAI 工作流，方案一未改采样器 |
| Scheduler | normal | 观察中 | 同上 |
| Steps | 第一遍 24 / 第二遍 12 | 观察中 | 第二遍可选 |
| CFG | 第一遍 5 / 第二遍 4.5 | 观察中 | 沿用原工作流 |
| Denoise | 第一遍 **1.00** / 第二遍 **0.15** | 观察中 | v2 第二遍只吃 Seam Mask；接缝仍在时先加宽 Seam / 加模糊，不要直接把 0.15 拉到 0.30 |
| AutoClothes Phase 1 Denoise | **0.95** | 未测 | 真换装 Mode A 起点。残影先补 Mask，再试 1.00 |
| Generation Mask | Grow 12 / Blur 8 | 观察中 | v2 标准档，比 v1 略大，让生成吃进少量接触区 |
| Composite Mask | Grow 6 / Blur 12 | 观察中 | 比 Generation 更保守、更柔，用来贴回原图 |
| Seam Mask | Outer +10 / Inner -4 / Blur 6 | 观察中 | 本机 GrowMask 支持负数，自动做接缝环带 |
| Resolution | 800 × 1216 | 观察中 | 方案一指定，不要为对齐 832 擅自改基线 |
| Seed | 114514 / fixed | 规范 | 对照实验必须固定 |
