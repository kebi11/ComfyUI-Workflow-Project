## 已登记节点

### VAE Encode (for Inpainting)

```text
节点名称：  VAEEncodeForInpaint
节点包：    comfy-core
用途：      编码原图时擦除 Mask 区域旧像素，并只在 Mask 内采样
输入：      IMAGE / VAE / MASK / grow_mask_by
输出：      LATENT（带 noise_mask）
关键参数：  grow_mask_by
当前推荐参数： 6（VAE 8px 网格防缝，不要再加大去代替手绘 Mask）
与其他节点关系： 后面接 SetLatentNoiseMask，把软边 Mask 写回去
显存影响：  与普通 VAEEncode 相当
已知问题：  内部会对 Mask 做 round()，单独用会变成硬边
注意事项：  这是方案一人物锁定的主机制。MASK 外不应被重绘
```

### GrowMask / ImageBlur / SetLatentNoiseMask

```text
节点名称：  GrowMask + ImageBlur + SetLatentNoiseMask
节点包：    comfy-core
用途：      工作分辨率下扩张并模糊服装 Mask，再写回 latent
输入：      MASK / IMAGE
输出：      软边 MASK / 带软边 noise_mask 的 LATENT
关键参数：  Grow expand=8；Blur radius=6, sigma=1.5
当前推荐参数： 同上，待实测后再改
与其他节点关系： LoadImage.MASK → 对齐 800×1216 → Grow → Blur → Inpaint
显存影响：  可忽略
已知问题：  FeatherMask 只虚化画布四边，不能当衣缘模糊用
注意事项：  Grow / Blur 必须在 800×1216 之后做，像素值才有意义
```

### Inpaint Crop / Stitch（新主线）

```text
节点名称：  InpaintCropImproved / InpaintStitchImproved
节点包：    lquesada/ComfyUI-Inpaint-CropAndStitch
用途：      按 Mask 裁局部送进 SDXL，再缝回原图；Mask 外不进 VAE
输入：      IMAGE / MASK / optional_context_mask
输出：      STITCHER / cropped_image / cropped_mask → 成品 IMAGE
关键参数：  expand=14；blend=16；context=1.8；target=1024；device=cpu
当前推荐参数： 同上。EXP-009 另接 Context Mask，Nearby=24
与其他节点关系： cropped_* → Fooocus Inpaint；成品 ← Stitch
显存影响：  CPU 模式几乎不占 VRAM，VRAM 留给 WAI
已知问题：  原图和 Mask 必须同尺寸。optional_context_mask 只扩窗口，不编码风格
注意事项：  6GB 先 CPU；OOM 再把 1024 改 896。Crop 面积看原图窗口，不要用 1024 预览尺寸
```

### Segformer 共享模型 + Ultra V3（AutoClothes Phase 3）

```text
节点名称：  LayerMask: LoadSegformerModel
            LayerMask: SegformerClothesSetting
            LayerMask: SegformerUltraV3
            LayerMask: MaskGrow
            MaskComposite
节点包：    LayerStyle + comfy-core
用途：      一次加载 B2，衣服删除和人体保护分开出 Mask，再加减得到 Final Edit
输入：      IMAGE + 类别开关
输出：      MASK → InpaintCropImproved.mask
关键参数：  Garment Grow 4/4；Hard +2/1；Skin -2/1
当前推荐参数： 同上，EXP-007 未 Queue
与其他节点关系： Final Edit → Crop.mask；EXP-009 另把 Hard∪Skin∪NearBG 送 optional_context_mask
显存影响：  同一套 B2 推理三次，然后交给 WAI。Context 不再跑第四次 Segformer
已知问题：  Setting 内部写的是 b3 后缀，与 b2 同为 clothes，可以共用
注意事项：  MaskGrow invert_mask 必须 false；Color Match 保持 0
```

### Fooocus Inpaint（新主线）

```text
节点名称：  INPAINT_LoadFooocusInpaint
            INPAINT_ApplyFooocusInpaint
            INPAINT_VAEEncodeInpaintConditioning
节点包：    Acly/comfyui-inpaint-nodes
用途：      把 WAI SDXL 打成 inpaint 模型，并允许 denoise < 1.0
输入：      head+patch / MODEL+LATENT / positive+negative+VAE+pixels+mask
输出：      patched MODEL；inpaint 条件与 latent
关键参数：  head=fooocus_inpaint_head.pth；patch=inpaint_v26.fooocus.patch
当前推荐参数： 换装 denoise 0.95 起步
与其他节点关系： latent_inpaint → Apply；latent_samples → KSampler
显存影响：  patch 打在 WAI 上，与 checkpoint 同驻
已知问题：  patch 必须下完整（约 1.23GB）
注意事项：  不要再用核心 VAEEncodeForInpaint 替代这一组
```

### KSampler（方案一）

```text
节点名称：  KSampler
节点包：    comfy-core
用途：      只在服装 Mask 内重绘
输入：      MODEL / 正负条件 / LATENT
输出：      LATENT
关键参数：  第一遍 24 / 5 / euler_ancestral / normal / 0.30
           第二遍 12 / 4.5 / euler_ancestral / normal / 0.15
当前推荐参数： 见上，seed 固定 114514
与其他节点关系： 两遍都吃同一张服装 Mask
显存影响：  SDXL 800×1216、batch=1，本机 6 GB 应按能跑设计
已知问题：  未实测
注意事项：  第二遍可整组 Bypass；禁止改成整图 denoise
```
