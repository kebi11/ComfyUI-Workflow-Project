# 方案一 v3：基于当前工作流节点编号的 3 个定点修复分支开发文档

## 1. 文档目标

基于你当前已经形成的：

```text
方案一 v2
= 换装主流程
+ Composite Mask
+ Seam Mask
```

继续增加 **3 个定点修复分支**，专门解决你这张成品图里最明显的几个问题：

- 左腰到左大腿的白色残影 / 旧透明纱残留
- 裙摆下缘尤其左侧和中部的软糊感
- 腰线、上衣下摆、裙腰之间的“拼接感”
- 头发 / 手臂 / 新衣服之间的轻微漂浮边界

本次目标不是重做主工作流，而是在当前工作流后面增加：

```text
分支 A：结构修复
分支 B：腰线融合
分支 C：裙摆与边缘接缝
```

---

# 3. v3 的总原则

v3 不再做：

```text
整衣大范围再修一次
```

而改成：

```text
当前成品图
↓
A 修结构问题
↓
B 修腰线问题
↓
C 修裙摆和边缘问题
↓
最终输出
```

三个分支推荐：

- **顺序串联执行**
- 每个分支处理一个具体问题
- 每一步都尽量用 **小 Mask + 中低 denoise**

---

# 4. 三个修复分支的职责

## 分支 A：结构修复分支

用于修：

```text
左腰侧白色残影
左大腿前方拖影
旧透明纱残留
裙摆左侧不干净的白糊
```

本质：

> 清除旧衣结构残留，并重新建立黑色裙摆轮廓。

---

## 分支 B：腰线融合分支

用于修：

```text
上衣下摆
黑色高腰部分
裙腰起始处
腰线与腹部/胯部贴合关系
```

本质：

> 让上衣、腰线、裙子三者看起来属于同一件服装系统。

---

## 分支 C：裙摆与边缘接缝分支

用于修：

```text
裙摆正中下缘
裙摆左下缘
裙摆与腿的边界
裙摆与背景的边界
必要时少量头发/衣服边界
```

本质：

> 去掉最后的分层感和“贴片感”。

## 6.2 分支 A 的 Mask

### Mask 名称

```text

```

### 覆盖区域

# 10. 三个分支的执行顺序

必须按顺序串联：

```text
41 当前成品
↓
A 结构修复
↓
B 腰线融合
↓
C 裙摆接缝
↓
60 最终保存
```

原因：

### 先 A
先把最脏的残影和旧结构清掉。

### 再 B
在结构基本正确后，修服装整体关系。

### 最后 C
最后只消除边界问题，避免前两步被再次打乱。

---

# 11. 每个分支是否可以跳过

可以。

## 如果残影已经很干净
跳过 A，直接做 B。

## 如果腰线已经自然
跳过 B，只做 C。

## 如果裙摆边缘已经自然
只做 A 或 A+B。

因此 v3 实际是：

> 三个可独立启用的小修复工具，而不是永远必须三连跑。

# 14. 故障与回退规则

## A 后裙子整体形状变差

说明：

```text
Structure Fix Mask 画太大
或
Denoise 太高
```

回退：

```text
缩小 A Mask
Denoise 0.22 → 0.20
```

---

## B 后腰线变糊

说明：

```text
Waist Blend Mask 太大
或
Denoise 太高
```

回退：

```text
缩小腰线 Mask
Denoise 0.12 → 0.10
```

---

## C 后裙摆边缘更假

说明：

```text
Hem Seam Mask 太宽
```

回退：

```text
缩窄 C Mask
保持低 denoise
```

---

## 发丝被破坏

说明：

```text
C Mask 或 B Mask 吃进了头发
```

回退：

```text
把发丝边界从当前 Mask 里剔除
```

头发单独修，不和裙摆一起修。

---

# 15. v3 的核心升级点

v2 主要解决的是：

```text
整件衣服的生成与大接缝问题
```

v3 解决的是：

```text
局部残影
局部腰线融合
局部裙摆边缘
```

本质上从：

```text
“整衣修”
```

变成：

```text
“定点修”
```

---

# 16. 最终原则

对于你这种：

> 头部、肤色、身材、背景尽量不变，只换衣服

的任务，成品阶段不要再依赖：

```text
大 Mask
高 denoise
整衣重修
```

而应该依赖：

```text
小 Mask
低到中等 denoise
按问题拆分
逐块修复
每步 Composite 锁定
```

这就是当前工作流从 **v2 防分层** 进到 **v3 成品优化** 的主要方向。
