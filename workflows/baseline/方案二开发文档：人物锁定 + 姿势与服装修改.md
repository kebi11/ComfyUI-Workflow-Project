# 方案二开发文档：人物锁定 + 姿势与服装修改

## 1. 文档目的

在当前 WAI Img2Img 工作流上开发主要生产工作流：

> 保持人物身份、头部、肤色和体型特征，同时允许改变姿势和服饰。

推荐名称：

`02_WAI_人物锁定_姿势服装编辑.json`

---

# 2. 与方案一的区别

方案一：

```text
人物姿势不改变
↓
只局部修改服装
```

方案二：

```text
人物身份保持
+
姿势允许变化
+
服饰允许变化
```

由于姿势变化会改变人物轮廓，因此不能保证全部原始身体像素继续存在。

开发目标变为：

> 保持人物视觉身份和身体比例，而不是保持身体像素完全一致。

---

最高优先级：

脸型
五官

```text
手臂位置

手势
服装
服饰附件
轻度视角变化
```

```text

```

均不应该直接决定结果。

---

# 7. DWPose

目标：

```text
姿态图
↓
人体骨架
```

优先提取：

```text
Body
Hands
```

Face Pose 是否启用需实验决定。

由于要求原人物头部尽量不变化：

第一阶段建议：

```text
Face Pose 不作为强控制项
```

避免目标姿势参考图的头部形状影响人物。

---

# 8. ControlNet 参数

初始：

```text
Strength: 0.70
Start: 0.00
End: 0.70
```

测试矩阵：

```text
0.55
0.65
0.70
0.75
0.85
```

目标：

找到最低的、能够稳定实现姿势的强度。

禁止默认：

```text
1.0
```

原因：

ControlNet 越强，越容易为了匹配姿态重新解释身体结构。

---

# 9. Mask 设计

方案二不能简单 Mask 全身。

采用：

> 最小必要重绘区域。

例如：

原图：

```text
左手叉腰
右手自然下垂
双腿交叉
```

目标：

```text
左手扶帽
右手拿包
双腿自然站立
```

推荐 Mask：

```text
头部           ×
脸             ×
主要头发       ×

左臂           √
右臂           √
新动作涉及的手 √

服装           √

腿部变化区域   √

身体交界区域   △

未变化裸露皮肤 ×
背景           ×
```

---

# 10. 头部保护区

建立一个明确规则：

```text
HEAD PROTECTED AREA
```

默认包括：

```text
完整脸
耳朵
头发主体
额头
下巴
头顶
```

若目标姿势没有明显改变头部角度：

```text
整个头部禁止进入 Mask
```

---

# 11. 头部方向变化限制

该方案主要用于：

```text
正面 → 轻度侧面
正常站姿 → 新站姿
轻度身体转动
手臂和腿动作改变
```

不用于：

```text
正面 → 完全背面
大幅低头
大幅仰头
180° 回头
强透视变化
```

这些交由方案三。

---

# 12. 身材锁定 Prompt

建立永久固定 Character Core：

long legs,
slim waist,

delicate body proportions,

# 13. 姿势 Prompt

Prompt 可以描述：

```text

sitting,
hand on hip,
raising arm,
crossed legs,
walking,
looking at viewer
```

但：

> Pose Prompt 只是辅助，真正姿势由 ControlNet 控制。

---

# 14. 第一遍 KSampler

建议：

```text
Steps: 24
CFG: 5
Sampler: euler_ancestral
Scheduler: normal
```

Denoise 根据姿势变化幅度：

### 小幅

```text
0.25–0.32
```

### 中幅

```text
0.32–0.42
```

### 较大

```text
0.42–0.50
```

超过：

```text
0.50
```

应考虑切换方案三。

---

# 15. 第二遍精修

保留当前两遍采样设计，但第二遍重新定义为：

```text
结构修补
```

推荐：

```text
Steps: 12
CFG: 4.5
Denoise: 0.12–0.18
```

第二遍重点：

```text
手
衣服边缘
身体接缝
局部结构错误
```

不要重新处理完整头部。

---

# 16. IPAdapter 可选模块

默认：

```text
关闭
```

如果发现：

- 身材容易漂移
- 新生成皮肤明显偏色
- 人物整体气质逐渐变化

再增加：

```text
原人物图
↓
IPAdapter SDXL
↓
低权重辅助
```

初始：

```text
Weight = 0.30
```

建议测试：

```text
0.25
0.30
0.35
0.40
```

上限原则上：

```text
≤ 0.45
```

它的职责只是：

> 提供人物整体视觉约束。

不是重新生成角色。

```

```

不要同时启用：

```text

```

```text
1 × OpenPose ControlNet

```

# 18. 调试顺序

开发时必须逐层增加功能。

### EXP-01

```text
原工作流
+
Inpaint
```

确认 Mask 正常。

### EXP-02

```text
+ DWPose
+ OpenPose
```

确认姿势能够变化。

### EXP-03

寻找：

```text
Denoise
×
Control Strength
```

最佳组合。

### EXP-04

测试身材一致性。

### EXP-05

如确有必要才加入低权重 IPAdapter。

---

# 20. 验收标准

使用同一原人物测试：

```text
至少 5 个姿势
×
至少 3 套服装
```

检查：

- [ ] 五官身份一致
- [ ] 发色一致
- [ ] 发型主体一致
- [ ] 肤色肉眼一致
- [ ] 身材仍然高挑纤细
- [ ] 肩宽没有明显漂移
- [ ] 腰宽没有明显漂移
- [ ] 腿长比例没有明显变化
- [ ] 指定姿势成功
- [ ] 指定服装成功
- [ ] 背景没有无意义大改
- [ ] 无明显 Inpaint 接缝
