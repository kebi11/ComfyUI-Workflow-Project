## 当前清单

### [P01] 换装后腰臀比例容易发生变化

- 状态：观察中
- 优先级：身材一致性
- 现象：目标服装改变后，体型跟着旧衣服剪影走。`宁.jpg` 去旧红裙后腰腹仍像被裹裙体积带着
- 可能环节：Mask 吃进腰侧皮肤；Grow 过大；缺少独立 body lock
- 相关实验：宁.jpg Phase 2 成品；EXP-007 Phase 3 拆出 Skin Core（Shrink -2）
- 下一步：先看 Phase 3 Final Edit 是否还吞腰。吞则加强 Skin Protect；不吞则认定已转成生成问题

### [P02] 大幅改变姿势时面部一致性下降

- 状态：开放（待基线复现）
- 优先级：面部一致性

- 相关实验：暂无

### [P03] IPAdapter 权重过高时会继承参考图服装

- 状态：开放（待基线复现）

- 相关实验：暂无
- 下一步：单变量扫描 weight，记录身份收益与服装泄漏的拐点

### [P04] 高分辨率时显存不足

- 相关实验：EXP-005 已出图，无 OOM 记录
- 下一步：不要默认加 SAM2 / VITMatte；OOM 时 Segformer 改 CPU 或 Crop 改 896
