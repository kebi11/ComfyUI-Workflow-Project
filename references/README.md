# references/

按参考信息的**职责**分类，不要把所有图片堆在一个文件夹。

| 目录 | 用途 |
|---|---|
| `character/` | 完整人物参考 |
| `face/` | 身份、五官、面部结构 |
| `body/` | 身材、比例、体型 |
| `pose/` | OpenPose / 姿态控制 |
| `clothing/` | 目标服装 |
| `style/` | 绘画风格 |
| `composition/` | 镜头与构图 |

## 规则

- 一张图只放进它主要服务的职责目录；多用途可复制并在文件名标明
- 这里只放参考，不放生成结果
- 建议命名：`角色名_用途_简要说明.ext`

放入素材后，在对应子目录 README 里登记文件名和用途。
