# 高级自动换装工作流 v1｜依赖安装清单

## 1. 适用环境

- ComfyUI
- Checkpoint：`waiIllustriousSDXL_v170.safetensors`
- GPU：RTX 4050 Laptop 6GB
- 目标工作流：`WAI_AutoClothes_Inpaint_v1`

> 注意：插件更新后节点显示名可能略有变化，以当前安装版本为准。

---

## 2. 必装插件

### 2.1 ComfyUI_LayerStyle

GitHub：
https://github.com/chflame163/ComfyUI_LayerStyle

用途：
- 自动服装分割
- Mask 处理
- VITMatte / MaskEdgeUltraDetail 边缘精修

重点节点：
- `SegformerB2ClothesUltra`
- `MaskEdgeUltraDetailV2`
- `MaskEdgeUltraDetailV3`

安装：
```bash
cd ComfyUI/custom_nodes
git clone https://github.com/chflame163/ComfyUI_LayerStyle.git
```

优先推荐通过 ComfyUI-Manager 安装，以便自动处理依赖。

---

### 2.2 Cozy Human Parser

GitHub：
https://github.com/cozymantis/human-parser-comfyui-node

用途：
- 人体/服装语义解析
- ATR / LIP 人体分割
- 生成 face / hair / arms / legs / clothes 等保护区

安装：
```bash
cd ComfyUI/custom_nodes
git clone https://github.com/cozymantis/human-parser-comfyui-node.git
```

然后按仓库 README 安装 requirements，并将所需 parser 模型放入其要求的 `models/schp` 目录。

本项目优先：
```text
ATR
```

因为它更偏服装/时尚解析。

第二选择：
```text
LIP
```

用于复杂人体场景对照。

---

### 2.3 ComfyUI Segment Anything 2

GitHub：
https://github.com/kijai/ComfyUI-segment-anything-2

用途：
- 基于已有粗 Mask/BBox 精修轮廓
- 裙摆、衣服边缘、复杂遮挡处轮廓修正

安装：
```bash
cd ComfyUI/custom_nodes
git clone https://github.com/kijai/ComfyUI-segment-anything-2.git
```

模型首选：
```text
SAM2.1 Base+
```

不优先 Large，原因：
- 4050 6GB 更容易运行
- 当前任务单图局部分割，Base+ 已足够作为第一基线

---

### 2.4 Inpaint Crop & Stitch

GitHub：
https://github.com/lquesada/ComfyUI-Inpaint-CropAndStitch

用途：
- 根据 Mask 自动裁局部
- 局部送入 SDXL Inpaint
- Stitch 回原图
- 尽量避免 Mask 外区域经历 VAE round-trip

安装：
```bash
cd ComfyUI/custom_nodes
git clone https://github.com/lquesada/ComfyUI-Inpaint-CropAndStitch.git
```

---

### 2.5 ComfyUI Inpaint Nodes / Fooocus Inpaint

GitHub：
https://github.com/Acly/comfyui-inpaint-nodes

用途：
- Fooocus SDXL Inpaint Patch
- VAE Encode & Inpaint Conditioning
- 局部 Refine
- 可选 Masked Color Match

安装：
```bash
cd ComfyUI/custom_nodes
git clone https://github.com/Acly/comfyui-inpaint-nodes.git
```

Fooocus Inpaint 模型：
https://huggingface.co/lllyasviel/fooocus_inpaint/tree/main

推荐文件：
```text
fooocus_inpaint_head.pth
inpaint_v26.fooocus.patch
```

放置：
```text
ComfyUI/models/inpaint/
```

## 4. 安装优先级

建议严格按顺序：

### P0
1. `ComfyUI-Inpaint-CropAndStitch`
2. `comfyui-inpaint-nodes`

先验证：
```text
原图 + 手工临时 Mask
→ Crop
→ Fooocus Inpaint
→ Stitch
```

能够正常运行。

### P1
3. `ComfyUI_LayerStyle`

验证：
```text
SegformerB2ClothesUltra
```
能够正确识别上衣 / 裙子 / 连衣裙等。

### P2
4. `ComfyUI-segment-anything-2`

验证 SAM2 精修。

### P3
5. `human-parser-comfyui-node`

最后作为第二语义保险加入。

---

## 5. 4050 6GB 安装/运行原则

优先：
```text
Batch = 1
Crop/Stitch = CPU
局部 crop = 1024×1024
```

如果 OOM：
1. Crop/Stitch 确认走 CPU
2. crop 改 896×896
3. 暂时关闭 SAM2
4. 暂时关闭 VITMatte
5. 暂时关闭 Human Parser 第二路
6. 只保留 Segformer + Crop/Stitch + Fooocus Inpaint
