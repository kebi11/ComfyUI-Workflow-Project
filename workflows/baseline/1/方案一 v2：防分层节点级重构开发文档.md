# 方案一 v2：防分层节点级重构开发文档

## 1. 开发目标

本次不重做整个工作流，只解决换装后的：

- 衣服像“贴”上去；
- 衣缘存在明显分层；
- 衣服与皮肤/背景的光影不连续；
- 第二遍精修后仍有接缝；
- 为了修边导致人物其他区域发生变化。

核心升级：

```text
一张 Mask
↓
拆成三种 Mask

Generation Mask
Composite Mask
Seam Mask
```

---

## 2. 三种 Mask 的职责

### Generation Mask

负责：

> 给模型足够空间真正生成新衣服。

特点：

```text
范围稍大
边缘适度柔和
允许吃进少量皮肤/背景接触区
```

---

### Composite Mask

负责：

> 将新衣服自然贴回原图，但避免硬切边界。

特点：

```text
范围比 Generation Mask 更保守
边缘更柔和
```

---

### Seam Mask

负责：

> 第二遍只处理新衣服和原人物之间的接缝。

不是重做整件衣服，而是只修：

```text
衣领
袖口
腰线
裙摆
裤脚
鞋袜边缘
衣服与背景边缘
```

# 10. 新增 Seam Mask

```text

             └→ 36 GrowMask -4
```

```text

```


# 21. 分层故障判断

### 出现一条明显边界线

优先：

```text
Composite Blur ↑
Seam Blur ↑
```

---

### 没有明显线，但衣服像贴上去

优先：

```text
Generation Grow ↑
```

让生成区域吃进：

```text
少量皮肤
接触阴影
背景交界
```

---

### 新衣服侵蚀皮肤

优先：

```text
Generation Grow ↓
Composite Grow ↓
```

---

### 第二遍越修越假

优先：

```text
Seam Mask 缩小
Denoise 0.15 → 0.12
```

---

### 衣服本身不够精致

临时：

```text
Node 24
Seam Mask
↓
Generation Mask
```

完成整衣细节精修后再恢复。

---

# 22. 最终验收

同一个人物至少：

```text
3 套差异较大的服饰
```

检查：

- [ ] 衣服完整替换
- [ ] 衣领没有明显硬边
- [ ] 袖口自然
- [ ] 腰线自然
- [ ] 裙摆/裤脚自然
- [ ] 鞋袜边缘自然
- [ ] 衣服与背景没有贴片感
- [ ] 头部无可见变化
- [ ] 五官无可见变化
- [ ] 发型无可见变化
- [ ] 肤色无可见变化
- [ ] 身材无可见变化
- [ ] Mask 外背景保持原图
- [ ] 第二遍没有破坏衣服主体结构

---

# 23. v2 最核心原则

不要再让：

```text
一张 Mask
```

同时承担：

```text
生成
合成
精修
```

而应该明确分工：

```text
Generation Mask
= 模型在哪里重新造衣服

Composite Mask
= 新衣服怎么柔和贴回原图

Seam Mask
= 第二遍只修哪里
```

这就是方案一从 v1 升级到防分层 v2 的核心。
