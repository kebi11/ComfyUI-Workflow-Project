# 高级自动换装工作流 v1｜节点搭建顺序清单

## 1. 目标

本文档不是概念设计，而是实际搭建顺序。

目标工作流：

```text
WAI_AutoClothes_Inpaint_v1
```

建议先搭最小可运行版，再逐层增强。

---

# 2. Phase 0：建立测试基线

先准备：

- 一张固定人物原图
- 一个固定 Seed
- 一个明确换装目标
- WAI v17
- Batch = 1

测试案例建议固定为：

```text
原透明/白色裙装
→
white sleeveless blouse,
high-waisted opaque black pleated skirt
```

这样能同时测试：
- 旧衣残影
- 透明边缘
- 腰线
- 裙摆
- 人物保护

---

# 3. Phase 1：先搭 Inpaint 主干

## 节点 A1：Load Image
输入：
```text
原人物图
```

Phase 1 可临时手动画一个粗 Mask，只用于验证主干，不作为最终方案。

---

## 节点 A2：Inpaint Crop

输入：
```text
image ← Load Image
mask  ← 临时 Mask
```

建议起始参数：
```text
mask_fill_holes = true
mask_expand_pixels = 12
mask_blend_pixels = 16
context factor ≈ 1.7
target = 1024×1024
device = CPU
```

输出：
```text
stitch
cropped_image
cropped_mask
```

---

## 节点 A3：CheckpointLoaderSimple

选择：
```text
waiIllustriousSDXL_v170.safetensors
```

输出：
```text
MODEL
CLIP
VAE
```

---

## 节点 A4：Positive CLIPTextEncode

首测：
```text
masterpiece, best quality, amazing quality,
white sleeveless blouse,
high-waisted opaque black pleated skirt,
clean garment silhouette,
natural clothing folds,
natural clothing-body contact,
soft contact shadows,
consistent lighting
```

---

## 节点 A5：Negative CLIPTextEncode

首测：
```text
bad quality, worst quality, worst detail,
double clothing,
ghost fabric,
floating cloth,
blurry hemline
```

---

## 节点 A6：VAE Encode & Inpaint Conditioning

输入：
```text
positive ← A4
negative ← A5
vae      ← A3 VAE
pixels   ← A2 cropped_image
mask     ← A2 cropped_mask
```

输出：
```text
positive
negative
latent_inpaint
latent_samples
```

---

## 节点 A7：Load Fooocus Inpaint

选择：
```text
fooocus_inpaint_head.pth
inpaint_v26.fooocus.patch
```

---

## 节点 A8：Apply Fooocus Inpaint

输入：
```text
MODEL  ← A3 MODEL
patch  ← A7
latent ← A6 latent_inpaint
```

输出：
```text
patched MODEL
```

---

## 节点 A9：KSampler

输入：
```text
model        ← A8
positive     ← A6 positive
negative     ← A6 negative
latent_image ← A6 latent_samples
```

首测：
```text
Seed = fixed
Steps = 24
CFG = 5.0
Sampler = euler_ancestral
Scheduler = normal
Denoise = 0.95
```

---

## 节点 A10：VAEDecode

输入：
```text
samples ← A9
vae     ← A3 VAE
```

---

## 节点 A11：Inpaint Stitch

输入：
```text
stitch          ← A2 stitch
inpainted_image ← A10
```

---

## 节点 A12：PreviewImage / SaveImage

Phase 1 完成。

### Phase 1 验收
- [ ] 能成功出图
- [ ] Mask 外区域基本不变
- [ ] 新衣服成功生成
- [ ] Stitch 无严重硬边
- [ ] 6GB 显存可完成

Phase 1 不通过时，不继续加入自动 Mask。

---

# 4. Phase 2：接入 Segformer 自动服装 Mask

删除 Phase 1 临时手绘 Mask 作为正式入口。

新增：

## 节点 B1：SegformerB2ClothesUltra

输入：
```text
原图
```

根据任务选择类别。

### 模式：只换上衣
```text
Upper-clothes
Coat
```

### 模式：只换下装
```text
Skirt
Pants
```

### 模式：整套服装
```text
Upper-clothes
Dress
Coat
Skirt
Pants
Belt
Socks
Shoes
```

输出：
```text
Clothes Semantic Mask
```

---

## 节点 B2：Mask Preview

必须显示：
```text
Clothes Semantic Mask
```

用途：
开发阶段肉眼检查语义分割是否正确。

---

## 节点 B3：基础 Mask 修整

先只做最轻量：
```text
Grow 4~8 px
少量 Blur
```

然后送：
```text
Inpaint Crop
```

### Phase 2 验收
- [ ] 无需手画即可识别主要衣服
- [ ] 不大量吃到脸和头发
- [ ] 不严重漏掉裙摆
- [ ] 可自动完成至少 3 次同类换装

---

# 5. Phase 3：增加人物保护区

目标：
即使 Segformer 将头发/皮肤误判到衣服边界，也要自动扣除。

## 节点 C1：生成 Face Mask
来源：
```text
Segformer 或 Human Parser
```

## 节点 C2：生成 Hair Mask

## 节点 C3：生成 Arms Mask

## 节点 C4：生成 Legs Mask

第一版可只保护：
```text
Face + Hair
```

确认稳定后再增加手臂/腿。

---

## 节点 C5：Protected Mask Union

合并：
```text
Face
+
Hair
+
按需 Arms
+
按需 Legs
```

得到：
```text
Protected Mask
```

---

## 节点 C6：Mask Subtract

逻辑：
```text
Edit Candidate Mask
=
Clothes Semantic Mask
-
Protected Mask
```

输出：
```text
Protected Clothes Mask
```

---

## 节点 C7：Preview

同时预览：
1. Clothes Semantic Mask
2. Protected Mask
3. Protected Clothes Mask

### Phase 3 验收
- [ ] 脸完全不在编辑区
- [ ] 头发主体不在编辑区
- [ ] 无关裸露皮肤明显减少
- [ ] 衣服主体仍完整

---

# 6. Phase 4：接入 SAM2 精修

## 节点 D1：SAM2 Model Loader

首选：
```text
SAM2.1 Base+
```

---

## 节点 D2：由 Protected Clothes Mask 生成 guidance

优先采用插件当前支持的：
```text
mask guidance
```

如该版本更适合 BBox，则：

```text
Protected Clothes Mask
→ Bounding Box
→ SAM2
```

---

## 节点 D3：SAM2 Segmentation

输入：
```text
image ← 原图
guidance ← D2
model ← D1
```

目标：
只精修已有服装候选区，不从零识别。

输出：
```text
SAM Refined Mask
```

---

## 节点 D4：Preview

A/B 同屏观察：
```text
Protected Clothes Mask
vs
SAM Refined Mask
```

### Phase 4 验收
重点看：
- 裙摆
- 腰线
- 袖口
- 头发压衣服处
- 鞋袜交界

如果 SAM2 反而扩大错误区域，可 Bypass 本模块。

---

# 7. Phase 5：接入 VITMatte / MaskEdgeUltraDetailV3

## 节点 E1：MaskEdgeUltraDetailV3

输入：
```text
image ← 原图
mask  ← SAM Refined Mask
```

输出：
```text
Final Edit Mask
```

第一版不要追求极端锐利边缘。

目标是：
- 去旧透明纱残留
- 改善半透明边缘
- 改善发丝/薄纱附近的 alpha 过渡

---

## 节点 E2：Final Mask Preview

必须保留。

建议同时预览：
```text
Segformer Mask
Protected Mask
SAM2 Mask
VITMatte Final Mask
```

这样任何一步出错都能定位。

---

## 节点 E3：连接回 Inpaint Crop

正式改为：
```text
Inpaint Crop mask
← Final Edit Mask
```

Phase 5 完成后，手工 Mask 不再进入主线。

---

# 8. Phase 6：Human Parser 第二语义保险

Human Parser 不建议最开始就接。

先在 Segformer 主线稳定后加入。

## 节点 F1：Human Parser ATR

输入：
```text
原图
```

输出所需类别：
```text
Upper-clothes
Skirt
Pants
Dress
Hair
Face
Arms
Legs
```

---

## 节点 F2：服装 Mask Fusion

有两种模式。

### Recall 模式
适合彻底去旧衣：
```text
Segformer Clothes
OR
ATR Clothes
```

优点：
更不容易漏掉旧透明衣服。

### Precision 模式
适合保护皮肤：
```text
Segformer Clothes
AND / Intersection
ATR Clothes
```

优点：
更保守。

正式工作流建议保留一个模式切换开关。

---

## 节点 F3：保护 Mask Fusion

保护区建议：
```text
Segformer Face/Hair
OR
ATR Face/Hair
```

保护区宁可稍大一点。

# 9. 最终主线

正式版结构：

```text

├─ Segformer Clothes
│
├─ Segformer Protect
│
├─ ATR Clothes
│

Mask Fusion
      ↓

      ↓

      ↓

      ↓
SaveImage
```

# 11. 工作流分组建议

ComfyUI 画布建议建立以下 Group：

```text
1 输入与模型
2 自动服装语义分割
3 人物保护区
4 Mask Fusion
5 SAM2 轮廓精修
6 VITMatte 边缘精修
7 Crop & Stitch
8 Fooocus Inpaint + WAI
9 预览与输出
```

每组增加一个 Note：
- 作用
- 默认参数
- Bypass 条件

# 13. Bypass 设计

必须允许：

### Bypass Human Parser
只用 Segformer。

### Bypass SAM2
当 SAM2 对动漫边缘判断反而变差时。

### Bypass VITMatte
普通不透明衣服不需要 alpha 精修时。

最终可以形成三档：

```text
FAST
Segformer
→ Crop
→ Inpaint

STANDARD
Segformer
→ Protected
→ SAM2
→ Crop
→ Inpaint

QUALITY
Segformer
→ Human Parser
→ Protected
→ SAM2
→ VITMatte
→ Crop
→ Inpaint
```

4050 6GB 日常优先：
```text
STANDARD
```

复杂透明衣服使用：
```text
QUALITY
```
