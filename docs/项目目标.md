# 项目目标

当前主线：可长期维护的**人物一致性工作流**。在改变姿势、服装、表情、镜头和背景时，人物仍然是同一个人。

## 必须保持

- 人物身份
- 面部结构
- 头部主要特征
- 发型主体结构
- 发色
- 肤色
- 身材比例
- 整体画风

## 允许改变

- 姿势
- 服装
- 表情
- 镜头
- 构图
- 背景

## 优先级

```text
人物身份
>
面部一致性
>
身材一致性
>
肤色一致性
>
风格一致性
>
姿势准确性
>
服装准确性
```

某方案若换装效果好，但身份或身材明显漂移，原则上不能直接认定为更优。

## 阶段目标

### 阶段 0：框架与基线

- [x] 按规范搭好仓库结构
- [ ] 补齐真实 ComfyUI 环境与模型清单
- [ ] 录入第一份可运行 Baseline

### 阶段 1：身份可复现

- [ ] 同一张人物参考、固定 seed，连续出图身份稳定
- [ ] 换表情 / 小幅换姿势后面部仍可辨认

### 阶段 2：体型与换装分离

- [ ] 换装时腰臀比、身高比例不明显漂移
- [ ] IPAdapter 高权重时尽量少继承参考图服装

### 阶段 3：姿势与构图可控

- [ ] 大幅改姿势后面部不崩
- [ ] 构图、镜头可调，身份仍锁定

### 阶段 4：正式发布

- [ ] 核心目标通过实测
- [ ] 6 GB VRAM 下可稳定跑通
- [ ] 晋升 `workflows/release/`
